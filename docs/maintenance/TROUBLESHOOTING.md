## Development environment

| Symptom                                                                                                                 | Cause and fix                                                                                                                                                                                                                                                                                                                                               |
| :---------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm ci` / `npm install` fails with `EBADENGINE`                                                                        | `.npmrc` sets `engine-strict=true` and jsdom needs Node `^22.22.2 \|\| ^24.15.0 \|\| >=26`. Use Node 24 (the version CI uses).                                                                                                                                                                                                                              |
| `npm ci` says the lock file is out of sync                                                                              | Run `npm install` locally, commit the updated `package-lock.json`.                                                                                                                                                                                                                                                                                          |
| `npm run lint` reports hundreds of unformatted files you did not touch (Windows)                                        | Your working tree has CRLF line endings from before `.gitattributes` forced LF. The committed content is fine. Check content only with `npx prettier --check . --end-of-line auto`, or judge by the files you changed. See [SETUP](../development/SETUP.md#line-endings-on-windows).                                                                        |
| A component test times out ("Test timed out in 5000ms") or misses an element in a full `vitest --run`, but passes alone | The full parallel run is CPU-bound and slows PBKDF2/IndexedDB-heavy tests 3–5×. The four known cases (`alertsPaging`, `budgetPerformanceCard`, `holdingEditDialog`, `lockScreenLockout`) now carry per-file timeouts; for a new one see [TESTING](../testing/TESTING.md#vitest-configuration). Re-run the file alone first; do not raise timeouts globally. |
| Playwright specs fail on timeouts, or a different spec fails each run                                                   | Something else is using the CPU, or `dist/` was rebuilt while the preview server was serving it. Run the suite alone, with one worker (the configured default), and do not build in parallel.                                                                                                                                                               |
| Playwright cannot find a browser                                                                                        | `npx playwright install chromium` (CI uses `npx playwright install --with-deps chromium`). `npm run test:e2e` runs a bare `playwright install`, which downloads every browser.                                                                                                                                                                              |
| Port 4173 or 5173 already in use                                                                                        | Stop the earlier `vite preview` / `vite` process. `playwright.config.ts` does not reuse an existing server, so Playwright refuses to start while port 4173 is taken.                                                                                                                                                                                        |
| The app shows stale UI after switching branches in dev                                                                  | A dev service worker (generated in `dev-dist/`) is serving old files. Unregister it and clear site data in the browser's developer tools.                                                                                                                                                                                                                   |
| `./gradlew` or `adb` not found                                                                                          | Expected: the Android toolchain is not required locally. Gradle runs in GitHub Actions only ([BUILD](../deployment/BUILD.md#checking-locally)).                                                                                                                                                                                                             |

## CI and APK build

| Symptom                                                                                        | Cause and fix                                                                                                                                                                                                                                           |
| :--------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Workflow does not start after a push                                                           | Push to `master` (not another branch) with the workflow file at `.github/workflows/build-apk.yml`, and check Actions is enabled. Or start it manually with **Run workflow**.                                                                            |
| `npm ci` fails in CI with `EBADENGINE` or "lock file out of sync"                              | The repo sets `engine-strict=true`, so the workflow's Node major (24) must satisfy every dependency. Run `npm install` locally, commit the updated `package-lock.json`, and keep `node-version` in the workflows in step with your dependencies.        |
| `dist/index.html is missing`                                                                   | The web build failed or wrote somewhere else. Read the **Build the web app** log; if you changed Vite's `build.outDir`, change `webDir` in `capacitor.config.ts` and the `dist/` paths in the workflow to match.                                        |
| `dist/sw.js exists`                                                                            | The APK build was run without `--mode capacitor`. A bundled service worker would keep serving the previous version's UI after an update.                                                                                                                |
| Gradle: "requires Java 21" / `Unsupported class file major version`                            | The **Set up Java 21** step must run before Gradle. Capacitor 8 and Android Gradle Plugin 8.13 need JDK 21.                                                                                                                                             |
| `./gradlew: Permission denied`                                                                 | Git lost the executable bit (common when committing from Windows). The **Make the Gradle wrapper executable** step handles it; keep that step.                                                                                                          |
| `SDK location not found`, `Failed to install the following SDK components`, or a licence error | The runner image no longer ships Android platform 36 / build-tools 36. Add a pinned `android-actions/setup-android` step after Java setup with `packages: platforms;android-36 build-tools;36.0.0`, or pin `runs-on` to an image version that has them. |
| `Keystore was tampered with, or password was incorrect`                                        | `android/app/debug.keystore` was replaced or regenerated with different credentials. It must be a PKCS12 file with alias `androiddebugkey` and password `android` (see `signingConfigs` in `android/app/build.gradle`).                                 |
| The signing fingerprint in the run summary changes between builds                              | The shared debug key is not being used. Check that `android/app/debug.keystore` is committed and not ignored (`git check-ignore -v android/app/debug.keystore` should print nothing).                                                                   |
| A build for an older commit was cancelled                                                      | Expected: the workflow cancels superseded runs on the same branch.                                                                                                                                                                                      |
| The release job fails with "Resource not accessible by integration"                            | See **Settings → Actions → General → Workflow permissions** and organisation policies on write tokens ([BUILD](../deployment/BUILD.md#repository-prerequisites)).                                                                                       |

## Installing and updating the APK

| Symptom                                                                             | Cause and fix                                                                                                                                                                                                                                                                      |
| :---------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Phone says **App not installed**                                                    | Usually a signature mismatch: the installed copy was signed with another key (an earlier build from before the keystore was committed, or one built elsewhere). Back up in the app, uninstall it, install again. Also caused by a lower version number or too little free storage. |
| Phone shows the old version after installing                                        | Check Settings → Apps → MyFin for the version. A build with a lower version number (commit count) than the installed one cannot replace it.                                                                                                                                        |
| **App updates** says "No update has been published yet"                             | No release exists. Push to `master` or run **Build Android APK** on `master`, and check that its **Publish GitHub Release** job passed. The repository must be public.                                                                                                             |
| **App updates** says GitHub is limiting requests                                    | GitHub allows about 60 anonymous API calls per hour per network address. Wait and try again.                                                                                                                                                                                       |
| In-app update ends with "App not installed" or says the update uses a different key | The installed copy was signed with another key, or is newer than the release. Back up, uninstall, and install the release APK by hand (see "Phone says App not installed").                                                                                                        |
| In-app update opens a settings screen instead of the installer                      | Android needs you to allow MyFin to **install unknown apps** once. Switch on **Allow from this source**, go back to MyFin, and tap **Install**.                                                                                                                                    |
| Auto-capture permission refused or "Notification access" greyed out                 | **App info → ⋮ → Allow restricted settings** ([Android app](../product/ANDROID_APP.md#auto-capture-of-bank-messages)).                                                                                                                                                             |

## Running app

| Symptom                                    | Cause and fix                                                                                                                                                                                                           |
| :----------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Blank screen on launch (Android)           | Update **Android System WebView** and Chrome from Google Play (the app needs a current WebView). To see errors, enable USB debugging and open `chrome://inspect` on a PC.                                               |
| "Save cancelled." when exporting (Android) | You dismissed the share sheet. Run the export again and pick a destination.                                                                                                                                             |
| `BlockedScreen` ("open in another tab")    | Another tab or window of the same browser profile holds the single-instance lock. Close it; the blocked tab polls every 2 seconds and takes over.                                                                       |
| A page is blank after a deployment         | The tab loaded chunks from the previous build. The app reloads once automatically (`lib/staleChunk.ts`); a manual reload also fixes it.                                                                                 |
| Forgotten PIN                              | There is no recovery by design. **Forgot your PIN?** on the lock screen is an explicit, typed-confirmation erase of the local data; afterwards restore from an encrypted backup (which needs the PIN it was made with). |
